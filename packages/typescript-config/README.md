# 📦 @rodrigo-work/typescript-config

Este pacote faz parte do monorepo **[rodrigo-work](https://github.com/rodrigo-work/rodrigo-work)** e fornece configurações padrão para projetos que utilizam **TypeScript**, ajudando na padronização e simplificação das configurações.

O pacote inclui um conjunto de arquivos de configuração prontos para o uso, como `tsconfig.json`, configuração para **ESLint** e **Prettier**, além de outras configurações que ajudam a melhorar a produtividade e a qualidade do código em projetos TypeScript.

---

## ⚙️ Funcionalidades

- Configuração padrão do `tsconfig.json` para TypeScript.
- Integração com ESLint, incluindo regras específicas para TypeScript.
- Configuração do Prettier para formatação automática de código.
- Simplificação do processo de configuração do ambiente TypeScript em novos projetos.
- Base para facilitar a integração com outras ferramentas de build, como Webpack e Babel.

---
