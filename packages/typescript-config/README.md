# @repo/tsconfig

Este pacote faz parte do monorepo **[rodrigo-work](https://github.com/rodrigo-work/rodrigo-work)** e fornece configurações padrão para projetos que utilizam **TypeScript**, ajudando na padronização e simplificação das configurações.

---

## Instalação

Para instalar o pacote `@repo/tsconfig`, execute o seguinte comando:

```bash
npx @rodrigo-work/cli add --name packages/tsconfig
```
