# @repo/next-config

Este pacote faz parte do monorepo **[rodrigo-work](https://github.com/rodrigo-work/rodrigo-work)** e fornece configurações padrão para projetos **Next.js**. O objetivo principal deste pacote é simplificar e padronizar a configuração de projetos Next.js, facilitando o processo de integração e ajudando a manter boas práticas em termos de desempenho, segurança e escalabilidade.

---

## Instalação

Para instalar o pacote `@repo/next-config`, execute o seguinte comando:

```bash
npx @rodrigo-work/cli add --name packages/next-config
```
