## 🧩 TAMANHOS PARA LOGO

### Usado em: sites, e-mails, apresentações, materiais impressos.

| Finalidade                        | Tamanho sugerido            | Observações                         |
| --------------------------------- | --------------------------- | ----------------------------------- |
| Header de site (desktop)          | 360x70 px                   | Tamanho comum, horizontal           |
| Header de site (mobile)           | 240x46 px                   | Versão menor para celular           |
| Retina display (HiDPI)            | 720x140 px                  | Dupla resolução para telas retina   |
| PDF ou impressão (alta resolução) | 1000x200 px ou SVG          | Prefira vetor (SVG, PDF)            |
| Slides / apresentações            | 600x120 px                  | Adaptado para PowerPoint ou Keynote |
| Redes sociais (adaptado)          | 1080x1080 px (centralizado) | Logo dentro de um fundo quadrado    |

## 🧩 TAMANHOS PARA ÍCONE

### Usado em: app, favicon, atalhos, mobile, PWA.

| Finalidade                        | Tamanho sugerido | Observações                               |
| --------------------------------- | ---------------- | ----------------------------------------- |
| Favicon padrão                    | 16x16 px         | Barra de navegação                        |
| Favicon retina                    | 32x32 px         | Aba do navegador                          |
| Favicon alta resolução            | 48x48 px         | Favoritos e atalhos                       |
| Web app (PWA) ícone               | 144x144 px       | Tela inicial de Android                   |
| Android App Icon (média)          | 96x96 px         | mdpi/hdpi devices                         |
| Android App Icon (alta resolução) | 192x192 px       | Play Store display                        |
| Ícone universal / símbolo geral   | 512x512 px       | Padrão do Google Play e ícones de desktop |
| iOS App Icon (Apple)              | 180x180 px       | Retina display (iPhone)                   |

## ✅ Resumo Rápido:

- Logo → Horizontal, vários tamanhos (ex: 360x70, 720x140)
- Ícone → Quadrado (ex: 144x144, 512x512), símbolo simplificado do logo
