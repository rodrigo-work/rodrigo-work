Este pacote faz parte do monorepo **[rodrigo-work](https://github.com/rodrigo-work/rodrigo-work)** e oferece soluções
de **observabilidade** para aplicações. O objetivo principal deste pacote é fornecer ferramentas para monitoramento, coleta
de métricas, logs e rastreamento distribuído, facilitando o diagnóstico e a melhoria do desempenho das aplicações.

## Instalação

Para instalar o pacote `@repo/observability`, execute o seguinte comando:

```package-install
npx @rodrigo-work/cli --name packages/observability
```
